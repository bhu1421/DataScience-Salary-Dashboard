# Data Science Salary Dashboard

An interactive **Microsoft Excel dashboard** developed to analyze salary trends across data-related job roles, countries, and employment types using a 2023 job-posting dataset.

## 📊 Project Overview

The dashboard allows users to compare salaries based on:

- Job Title
- Country
- Job Type

It uses Excel formulas, data validation, and visualizations to make salary analysis interactive.

## 🛠️ Excel Skills Used

- Data Cleaning & Organization
- Excel Formulas & Functions
- Structured Tables
- Data Validation
- Dashboard Design
- Data Visualization
- Map Charts

## 📈 Dashboard

### Salary by Job Title

A horizontal bar chart compares **median salaries across different data-related roles**.

### Salary by Country

A geographic map visualizes **median salary levels across countries** with available data.

## 🧮 Analysis

Used Excel functions such as:

- `MEDIAN` / `IF` — multi-criteria salary analysis
- `COUNTIFS` — job-posting counts
- `XLOOKUP` — lookup operations
- `UNIQUE` / `FILTER` / `SORT` — dynamic supporting lists
- `SUBSTITUTE` — text cleaning

## 🔎 Interactive Filters

Data Validation dropdowns allow users to select:

- Job Title
- Country
- Job Type

This enables dynamic salary comparisons based on the selected criteria.
